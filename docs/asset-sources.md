# Public asset source map

All image files in `public/brand` and `public/images` were recovered from the rendered public GFB website on 2026-10-26. They remain subject to GFB's rights review before production use. No INCAL imagery was copied.

The files preserve the visual references exposed by these current pages:

- Brand logo and home imagery: `https://www.gfb-solutions.com/`
- Packaging imagery: `https://www.gfb-solutions.com/packaging-solutions`
- Raw-material imagery: `https://www.gfb-solutions.com/raw-materials`
- Flavour imagery: `https://www.gfb-solutions.com/flavours-and-aromas`
- Consulting imagery: `https://www.gfb-solutions.com/consulting-solutions`

The downloaded responses were AVIF even when Wix filenames used PNG/JPG suffixes; local files therefore use the accurate `.avif` extension.
